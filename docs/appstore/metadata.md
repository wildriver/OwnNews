## 説明文(4000字以内)

```
ニュースを、食事のように。

OwnNewsは「情報的健康」を保つためのニュースリーダーです。あなたが何をどれだけ読んでいるかを栄養バランスとして可視化し、推薦アルゴリズムの主導権をプラットフォームからあなたの手に取り戻します。

■ こんな方におすすめ
・気づけば同じジャンルのニュースばかり読んでいる
・SNSやニュースアプリの「おすすめ」に流されている感覚がある
・自分の情報摂取のクセを客観的に知りたい
・政治も経済も国際もバランスよく、効率的に把握したい

■ 主な機能

【あなたのバブルと、バブルの外】
フィードは「あなたのバブル」（関心に近い記事）と「バブルの外」（普段読まないジャンルの記事）を常に並べて表示。読みたいものを読みながら、視野が狭まっていないかを一目で確認できます。視野の広さはスライダーでいつでも調整できます。

【情報的健康ダッシュボード】
閲覧履歴からジャンルバランス・栄養素スコア（事実性・文脈・多様な視点・感情度・速報性）を計算し、レーダーチャートで可視化。「見落としニュース」（みんなは読んでいるのに、あなたは読んでいない記事）もお知らせします。

【推薦エンジンはあなたの端末の中に】
最大の特徴は、推薦計算がすべてあなたの端末内で行われることです。あなたの関心を表すデータ（関心ベクトル）はサーバに送信されません。「何に興味があるか」という最もセンシティブな情報を、運営者でさえ見ることができない設計です。

【毎日の読むきっかけ】
朝・昼・午後・夕方・夜の1日5回、ニュースをチェックするきっかけをお届けします。通知は端末内で完結し、オフにすることもできます。

【幅広いニュースソース】
国内の主要メディアから地方紙まで、幅広いソースの記事を配信。ジャンルの偏りが出ないよう、配信全体の比率を保ったままお届けします。

■ 研究プロジェクトとして
OwnNewsは、フィルターバブルの可視化と情報的健康の実現をテーマとする大学研究室の研究プロジェクトです。営利を目的とせず、広告もありません。

あなたのニュースとの付き合い方を、今日から少しだけ健康に。
```

## 年齢制限指定(Age Rating)の回答

すべて「なし」で回答 → **4+** になる想定。
ニュースアプリなので「頻繁/極端な成人向けテーマ」等には該当しない。
「制限のないWebアクセス」は **いいえ**（アプリ内ブラウザは記事表示のみで自由なURL入力は不可）。

※ 記事に暴力的なニュースが含まれる可能性を考慮する場合は
「まれ/軽度な 現実的暴力」を選ぶと 12+ になる。ニュースアプリの前例では4+/12+どちらもある。
迷ったら12+が安全。

## App Privacy（プライバシー質問票）の回答

「データの収集」: **はい、収集します**

### 収集するデータタイプ

| データタイプ | 用途 | ユーザーに紐付く | トラッキング |
|---|---|---|---|
| メールアドレス | アプリの機能(アカウント・同期) | はい | いいえ |
| 製品の操作(閲覧・リアクション履歴) | アプリの機能(端末間同期・見落としニュース) | はい | いいえ |

### 収集しないもの(明示的に「いいえ」)

- 位置情報 / 連絡先 / 写真 / 健康データ / 財務情報 / 検索履歴 / 識別子(IDFA等) / 診断データ

### 補足(審査ノートにも記載)

- 推薦計算・関心ベクトルは端末内で完結し、サーバに送信されない
- トラッキング(ATT)は一切行わない → App Tracking Transparencyの許可要求なし
- 広告なし

## 輸出コンプライアンス(Export Compliance)

- 「暗号化を使用していますか?」→ **はい**(HTTPS)
- 「免除に該当しますか?」→ **はい**(標準的なHTTPS/TLSのみ使用)
- ITSAppUsesNonExemptEncryption = false をInfo.plistに追加済みであれば毎回の質問はスキップされる
